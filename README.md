# ReverbWane

ReverbWane leverages multi-threaded, distributed processing for real-time, low-latency audio rendering across scalable server clusters.

ReverbWane is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/ReverbWane.git`
2. `cd ReverbWane`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure ReverbWane, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
